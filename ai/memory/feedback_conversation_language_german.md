Reply to the user in German by default, from the very first reply of a session. Separate
from [[feedback_english_only]], which covers everything written to disk.

**Why:** Standing preference since 2026-08-23; re-stated with frustration on 2026-09-04
("deutsch bitte. merken... endlich") because it kept being dropped at session start. It is
therefore also pinned in `.claude/CLAUDE.md`, which is always loaded.

**How to apply:** German prose in chat; code blocks, file contents, commit messages and
OpenSpec artifacts stay English.
