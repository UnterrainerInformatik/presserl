Everything in the repo — Java and TypeScript identifiers, comments, log messages, docs,
OpenSpec artifacts, commit messages — is English. No German.

**Why:** Project-wide rule stated by Gerald.

**How to apply:** Anything you add or rewrite is English. User-facing UI text in the
frontend is a separate concern: it belongs in i18n resources (e.g. `en`/`de` message files),
not hard-coded in components.
